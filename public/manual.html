🚀 Visão Geral do Projeto

O WebMSX & Ollama AI Bridge é uma solução de engenharia que conecta a arquitetura clássica de 8-bits dos microcomputadores MSX (1983) com modelos de inteligência artificial de última geração (Qwen2.5-Coder e Llama-3.2) rodando 100% localmente com aceleração por GPU no seu próprio computador.

🏗️ 2. Arquitetura do Sistema & Hardware I/O

A comunicação entre o mundo 8-bits virtualizado e o Host moderno é realizada por três camadas perfeitamente sincronizadas:

┌───────────────────────────────────────────────────────────────────────────┐ │ FLUXO ARQUITETURAL COMPLETO │ └───────────────────────────────────────────────────────────────────────────┘ [ WebMSX Emulador ] │ (Z80 CPU executa LPRINT "AI:pergunta") ▼ [ Barramento I/O ] ── Porta 0x91 (Data Register) + Porta 0x90 (Status 0x00) │ (JavaScript intercepta via bus.connectOutputDevice) ▼ [ Bridge Client ] ── Envia POST /api/chat via HTTP para o Node.js │ ▼ [ Backend Node.js ] ── Express Middleware (server.js) │ ├─ Gerenciador de VRAM (ensureSingleModelLoaded) │ ├─ Sanitizador ASCII 7-bit (Remove acentos Unicode para VDP) │ └─ Formatador de Word-Wrap (38 colunas para SCREEN 0) ▼ [ Ollama Host ] ─── Modelos na GPU NVIDIA GTX 1630 (CUDA 13.2) │ (Qwen2.5-Coder:1.5b / 3b / Llama3.2:1b) ▼ [ Retorno ao MSX ] ─ Injeção via Circular Keyboard Buffer (0xFBF0) │ ▼ [ Tela do MSX ] ──── LINE INPUT ""; R$ recebe o texto e imprime no monitor!

PORTA 0x91 Registrador de Dados

Captura cada caractere emitido pelo comando LPRINT do Z80 sem interferir na memória RAM do MSX.

PORTA 0x90 Status de Impressora

Retorna 0x00 (Bit 1 em nível baixo = Not Busy), garantindo que a rotina LPTOUT do BIOS nunca entre em espera infinita.

VRAM OPTIMIZER Gestão de Memória

Descarrega automaticamente modelos inativos para que 100% da VRAM da GTX 1630 fique livre para o modelo em uso.

⚡ 3. Aceleração por GPU NVIDIA

O sistema foi calibrado para extrair a máxima performance da sua placa de vídeo NVIDIA GeForce GTX 1630 (4 GB VRAM):

🚀 qwen2.5-coder:1.5b

Recomendado para o dia a dia. Ocupa apenas 1.1 GB de VRAM. Responde e gera programas BASIC completos em 1 a 3 segundos.

🧠 qwen2.5-coder:3b

Para lógica complexa e jogos densos. Ocupa 1.8 GB de VRAM. Máxima precisão para rotinas matemáticas e de banco de dados.

💬 llama3.2:1b

Para conversação e bate-papo geral. Extremamente leve e ágil para respostas conceituais na tela do MSX.

Dica de Desempenho: O backend utiliza keep_alive: '60m' e num_ctx: 2048. Isso mantém o modelo pronto na VRAM e reduz o footprint de memória, gerando tokens até 3x mais rápido.

💬 4. Modo Chat & Assistente MSX (SCREEN 0)

Permite conversar com a inteligência artificial diretamente pela linha de comando clássica do MSX:

1

Auto-Carregamento

Clique em ⚡ Auto-Carregar CHAT.BAS. O sistema injeta o programa CHAT.BAS v1.2 com CLEAR 4000 na memória.

2

Perguntas no MSX

No prompt MSX>, digite qualquer pergunta (ex: Quem foi Alan Turing? ou O que e o chip Z80?) e aperte ENTER.

3

Exibição Formatada

A resposta retorna em ~0.8s, perfeitamente formatada em 40 colunas sem acentos truncados, pronta para a leitura.

💻 5. MSX BASIC Studio

Ambiente integrado para criar, editar, testar e salvar programas MSX BASIC com suporte de IA:

🪄 Gerador com IA Especializada

Descreva o que deseja (ex: "Crie um jogo de labirinto em SCREEN 1 com som e pontuacao"). A IA gera o código com linhas 10, 20, 30 e comandos em maiúsculas.

⚡ Injetar & Rodar no MSX

Com 1 clique, envia NEW, digita todo o código do editor e executa RUN no WebMSX ao vivo.

💾 Salvar .BAS

Faz o download do código fonte ASCII limpo pronto para carregar em disquetes, fitas K7 ou cartão SD de MSX real.

🔧 6. Depurador & Correção Automática com Memória do MSX

A ferramenta definitiva para corrigir bugs de código e erros do interpretador:

📦 Memória de Execução Ativa

Toda vez que você injeta um código no MSX, o sistema grava o código exato no badge 📦 Memória. A IA sempre sabe o que estava rodando.

📺 Captura de Erro da Tela

Lê a tela azul do MSX e detecta automaticamente mensagens como Syntax error in 30, Type mismatch in 80 ou Out of string space.

⏪ Restaurar da Memória

Se você limpar o editor por engano, pode restaurar o último programa que foi para o MSX com um único clique.

Como Depurar: Se o jogo travar ou der erro no MSX:
  1. Clique em 📺 Capturar Erro da Tela MSX.
  2. Clique em 🔧 Corrigir Código.
  3. O editor substitui o código antigo pelo código corrigido com animação de destaque.
  4. Clique em ⚡ Injetar & Rodar no MSX!

🕹️ 7. Compilador de Cartuchos .ROM (16KB Bootável)

O msx_rom_builder.js permite transformar qualquer código MSX BASIC em um Cartucho ROM binário real:

0x4000 Cabeçalho Oficial

Assinatura binária 0x41 0x42 ("AB") no início do cartucho, reconhecida por todas as BIOSes de MSX.

0x4010 Autostart Loader Z80

Código de máquina nativo Z80 que inicializa o vídeo, transfere o programa BASIC e executa o autostart no boot da máquina.

HARDWARE Compatibilidade Real

Funciona no WebMSX, openMSX, blueMSX ou gravado em cartuchos físicos como Carnivore2, MegaFlashROM e FlashROM.

❓ 9. Dúvidas Frequentes & Troubleshooting

Erro: "Out of string space"

O MSX BASIC reserva poucos bytes para texto por padrão. Adicione 5 CLEAR 4000 na primeira linha do seu programa para expandir a memória de strings.

Erro: "Syntax error in XX"

Clique em 📺 Capturar Erro da Tela MSX e em seguida em 🔧 Corrigir Código. A IA corrigirá a pontuação (ex: trocar vírgula por ponto e vírgula no INPUT) na hora.

Lentidão na geração com IA

Certifique-se de estar usando o modelo qwen2.5-coder:1.5b. O nosso otimizador de VRAM descarrega outros modelos da memória para garantir velocidade máxima.
